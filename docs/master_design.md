# THE CODER 主策划文档

## 版本更新

### v0.32
- 初始牌库调整为固定 16 张：
- 指令卡 9 张：`攻击×2`、`防御×2`、`治疗×1`、`循环×1`、`如果【】则+5（普通）×1`、`双击×1`、`蓄力×1`。
- 参数卡 7 张：`1×1`、`2×2`、`3×2`、`4×1`、`5×1`。
- 稀有度调整：`双击()` 由稀有改为普通；`蓄力()` 由稀有改为普通。
- 设计意图：提升初局策略深度，让玩家开局即接触 `如果` 玩法，并提高 `双击`/`蓄力` 连招可能性。

### v0.33
- UI 动画技术选型：优先使用 `Phaser.js` 缓动函数（无 Phaser 时自动回退）。
- 抽牌动画：从牌堆飞入手牌区，`alpha 0→1`，`300ms`，`Back.easeOut`，多张卡间隔 `50ms`。
- 弃牌动画：淡出并飞向弃牌堆，`alpha 1→0`，`200ms`，`Quad.easeIn`。
- 出牌动画：上浮放大后飞向编程区并吸附弹跳，`250ms`。
- 拖动反馈：选中卡牌上浮放大 `10%`，可放置区高亮，落点吸附弹跳。
- `如果`卡判断反馈：命中绿色闪烁（`0x00ff00`），失败红色闪烁（`0xff0000`）。

### v0.31
- `【如果】`卡机制简化：移除复杂条件分类，统一使用固定条件池。
- 加成类型简化：仅保留 `+5` 与 `×2` 两种。
- 条件按稀有度递进：
- 普通（2个）：`敌方血量<30%`、`我方血量>70%`。
- 稀有（4个）：普通 + `本回合未打出过参数型指令`、`本回合已造成过伤害`。
- 史诗（6个）：稀有 + `敌方血量<50%`、`我方血量>50%`。
- 编程区条件选择交互改为悬浮卡片式条件列表，点击 `【条件】` 弹出并在选中后自动关闭。

### v0.29
- 语法中文化：`for` 统一显示为 `循环`，`if` 统一显示为 `如果...则`。
- 示例规范：统一写作 `循环(3)`，`如果{×2}...则`。
- 角色技能描述规范：卡牌名称统一使用 `【】` 包裹。
- 插件描述规范：统一写作 `【循环】卡容量+1`、`【如果】卡容量+1`。

### v0.28
- 语法格式统一：循环写法统一为 `循环(N)`，用于代码库展示与敌人意图展示。
- 示例规范：统一写作 `循环(3)`。
- 容量信息策略调整：循环/如果 卡面不再显示 `[0/2]`，改为悬浮提示 `容量：0/2`。

## 语法展示规范
- 循环语法统一使用 `循环(N)`。
- 条件语法统一使用 `如果{...}...则` 样式。
- 面板展示遵循统一样式，避免同一功能出现多种写法。
