# UI 界面设计模块

## v0.28 交互更新

### 编程区交互
- 新增“点击悬空换行”：
- 第一步，点击编程区内已有指令卡，卡牌进入悬空状态。
- 第二步，点击目标空行，完成换行移动。
- 再次点击同一悬空卡可取消选择。

### 与手牌交互一致性
- 手牌放入编程区仍使用“选中卡牌后点击目标行”逻辑。
- 编程区卡牌换行交互与上述流程保持一致，降低学习成本。

### 容量提示
- 循环/如果 卡牌默认不显示 `[used/capacity]` 文本。
- 鼠标悬停时显示提示：`容量：used/capacity`。

## v0.29 文案规范
- 语法名称中文化：`for` 显示为 `循环`，`if` 显示为 `如果...则`。
- 卡牌名规范：条件语法卡统一使用 `如果{...}...则` 样式。
- 角色描述规范：卡牌名统一采用 `【循环】`、`【如果】` 包裹形式。

## v0.31 编程区条件交互
- `【如果】`卡条件入口由下拉框改为 `【条件】` 触发器。
- 点击触发器后显示悬浮卡片式条件列表（圆角、半透明样式）。
- 选中任一条件后，列表立即消失并写回当前卡牌条件。
- 条件池采用固定配置，并按卡牌稀有度显示递进数量（2/4/6）。

## v0.33 UI 动画细节
- 技术选型：`Phaser.js` 缓动函数作为首选，动画执行层支持回退实现。
- 抽牌：牌堆飞入手牌，`alpha 0→1`，`300ms`，`Back.easeOut`，多卡间隔 `50ms`。
- 弃牌：淡出并飞向弃牌堆，`alpha 1→0`，`200ms`，`Quad.easeIn`。
- 出牌：上浮放大后飞向编程区并吸附，整体时长 `250ms`。
- 拖动：选中上浮放大 `10%`，可放置区域高亮，放下后触发吸附弹跳。
- `如果`判定：命中绿色闪烁，失败红色闪烁。
- 手牌区 `如果` 卡交互：桌面端支持悬停/点击查看条件预览悬浮框，移动端采用点击触发。
